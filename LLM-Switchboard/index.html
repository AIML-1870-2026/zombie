⚠  Anthropic — Browser Requests Blocked
Anthropic's API blocks browser-originated requests (CORS). To use Anthropic models, run a local proxy that forwards requests server-side.
# Option 1 — Node.js (requires Node 18+)
npx local-cors-proxy --proxyUrl https://api.anthropic.com --port 8080
# Then set endpoint to: http://localhost:8080/v1/messages

# Option 2 — Use Anthropic's Workbench at console.anthropic.com
#             (no CORS issues, full model access, no proxy needed)
